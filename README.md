## 👨‍💻 About

현재 **x86 엔지니어**로서 하드웨어와 시스템 인프라에 대한 실무 경험을 쌓고 있으며, 업무와 학습을 통해 기술적 이해의 범위를 넓혀가고 있습니다.

단순히 주어진 업무를 수행하는 데 그치지 않고, 시스템이 동작하는 원리를 이해하고 관련 기술을 직접 실습하며 학습한 내용을 기록합니다.

이 저장소는 실무에서 얻은 경험과 개인적인 기술 학습을 축적하고, 다시 활용할 수 있도록 정리하는 기술 아카이브입니다.

- **Experience** — x86 기반 시스템 및 하드웨어 관련 실무 경험
- **Fundamentals** — 운영체제, 컴퓨터 구조 및 네트워크 원리 학습
- **Infrastructure** — Linux 서버 구축 및 운영 기술 학습
- **Virtualization** — 가상화 환경 구축과 관리
- **Automation** — 컨테이너 및 인프라 자동화
- **Expansion** — 클라우드 및 스토리지 기술 학습

## ✍️ Documentation Principles

- **Learn** — 새로운 기술과 개념을 지속적으로 학습합니다.
- **Understand** — 단순한 사용법보다 동작 원리와 구조를 이해합니다.
- **Practice** — 직접 환경을 구축하고 실습하며 검증합니다.
- **Troubleshoot** — 문제의 원인을 분석하고 해결 과정을 기록합니다.
- **Share** — 학습한 내용을 체계적으로 정리하고 다시 활용합니다.
